# Проект 7-го спринта

## Структура хранилища

- `/user/master/data/geo/events` — исходные события с координатами, parquet, партиции по `date`. Только читаем.
- `/user/s15105168/data/geo/geo.csv` — справочник городов Австралии. Загрузил один раз через `hdfs dfs -copyFromLocal`.
- `/user/s15105168/data/test/` — сюда пишу витрины, когда тестирую скрипты на коротком периоде.
- `/user/s15105168/data/analytics/` — готовые витрины для аналитиков:
  - `users_mart` — витрина по пользователям;
  - `zones_mart` — витрина по городам (зонам);
  - `friends_mart` — рекомендации друзей.

Витрины пишутся в parquet, в папку `date=<дата расчета>`. Обновляются раз в день через Airflow.



## Что и как считаю

**Город события.** Считаю расстояние от сообщения до центра каждого города по формуле из задания и беру ближайший город.

**Таймзоны.** В geo.csv их нет, поэтому я подсмотрел как делают другие студенты и сделал словарь с таймзонами, иначе `from_utc_timestamp` не работает.

**Время события.** У сообщений в каналы время лежит в `datetime`, у личных — в `message_ts`. В `message_ts` иногда стоит другой год, чем в партиции, поэтому дату беру из `date`, а из поля только часы-минуты-секунды.

**Рекомендации друзей.** Беру подписчиков одного канала, у которых известно последнее местоположение, делаю пары внутри канала и города и оставляю те, где расстояние не больше 1 км. Потом убираю пары, которые уже переписывались. Чтобы не было дублей, в паре всегда `user_left < user_right`. `zone_id` — город первого пользователя, `local_time` — время расчета в его таймзоне.
